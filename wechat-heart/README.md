# 💗 wechat-heart —— 微信扫码版「弹窗祝福」

这是 `114514.py`（tkinter 弹窗爱心 + 满屏祝福程序）的网页移植版。
把本项目部署到公网后，用微信「扫一扫」扫描二维码，**打开网页即自动运行整个动画，无需任何点击**。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部程序（单文件，无其他依赖，双击即可本地预览） |
| `make_qr.py` | 二维码 / 扫码卡片生成脚本 |
| `music.mp3` | 可选：放入本目录后，动画开始时会自动尝试播放背景音乐 |

## 一、本地预览

- 直接双击 `index.html` 即可运行；
- 或在项目目录运行 `python -m http.server 8000`，浏览器打开 <http://localhost:8000>；
- 同一 WiFi 下，手机浏览器访问 `http://<电脑IP>:8000` 也能体验（可先用 `make_qr.py` 生成局域网地址的二维码试扫）。

## 二、部署到公网（微信扫码打开）

推荐 **GitHub Pages**（免费、无需备案）：

1. 注册 GitHub：<https://github.com>；
2. 新建仓库（例如 `heart`，选 Public）；
3. 把本目录的 `index.html` 上传到仓库（网页端拖拽上传即可）；
4. 仓库页 → **Settings → Pages** → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/(root)` → **Save**；
5. 约 1 分钟后得到网址：`https://<你的用户名>.github.io/heart/`；
6. 生成二维码：`python make_qr.py "https://<你的用户名>.github.io/heart/"`，把 `二维码.png` 或 `扫码卡片.png` 发给对方。

其他选择：

- **Gitee Pages**（国内访问快）：仓库 → 服务 → Gitee Pages → 启动（需要实名认证的账号）；
- **Vercel / Netlify**：把 `index.html` 拖上去即可（部分域名在国内可能不稳定）；
- **自己的服务器 / 虚拟主机**：把 `index.html` 上传到网站根目录即可。

> 提示：微信里首次打开非官方域名会提示“非微信官方网页”，点“继续访问”即可，属正常现象。

## 三、生成二维码

```bash
python make_qr.py "你的网址"
```

产物：

- `二维码.png` —— 纯二维码，微信扫一扫直接识别；
- `扫码卡片.png` —— 带标题的海报，方便转发，长按图片也能识别。

## 四、自定义

- **改祝福语**：编辑 `index.html`，找到 `var tips = [...]` 数组，增删即可；
- **换背景音乐**：把音乐文件改名为 `music.mp3` 放进本目录（微信会拦截自动播放音乐：页面打开时会先尝试一次，首次触摸屏幕后会自动再试，无需任何点击）；
- **改标题 / 结束语**：直接改 `index.html` 中「有份小惊喜」「送给你」等文字。
